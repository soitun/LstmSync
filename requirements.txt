# ========== ONNX Runtime 跨平台说明（inference.py 会按 ort.get_available_providers() 自动判断） ==========
# Windows  + NVIDIA GPU      -> 上面这行 onnxruntime-gpu 即可；推理走 TensorRT → CUDA → CPU
# Windows  + 任意 GPU        -> pip uninstall onnxruntime-gpu && pip install onnxruntime-directml
#                                推理时 --device mps，会使用 DmlExecutionProvider（DirectML）
# Linux    + NVIDIA GPU      -> onnxruntime-gpu    （CUDA → CPU）
# macOS    Apple Silicon     -> pip uninstall onnxruntime-gpu && pip install onnxruntime-coreml
#                                或 pip install onnxruntime>=1.17   （--device mps → CoreML → CPU）
# 仅 CPU                     -> pip uninstall onnxruntime-gpu && pip install onnxruntime
#
# 注意：onnxruntime / onnxruntime-gpu / onnxruntime-directml / onnxruntime-coreml 互斥，切换平台时先卸载再装
# CoreMLExecutionProvider 仅在 macOS / iOS 可用；Windows 上 inference 即便传 "mps" 也会被
# _get_ort_providers() 动态识别为 DirectML（如果装了 onnxruntime-directml）否则退回 CPU。
